# Aydin Hoca - Ders Notlari

Aydin Hocanin isledigi ders notlari. Her hafta pazartesi ve carsamba guncellenir.

---

## Klasor Yapisi

```
dersler/           → Haftalik ders kodlari (C#)
sinav-notlari/     → Sinav sorulari, ozetler ve kesin cikacak konular
projeler/          → Buyuk proje ornekleri
gorseller/         → Graf teorisi ve ders gorselleri
```

## Sinav Konulari

### Graf Teorisi
- Euler Teoremi (Yolu ve Dongusu)
- Kapsayan Agac (Spanning Tree)
- Minimum Kapsayan Agac (MST - Kruskal / Prim)

### OOP (Nesne Yonelimli Programlama)
- Sinif (Class) ve Kurucu Metot (Constructor)
- Erisim Belirleyiciler (public / private)
- Kalitim / Miras (Inheritance)
- Polymorphism (Cok Bicimllik)
- Abstract Siniflar

### Algoritmalar ve C#
- Polindrom Sayi
- Armstrong Sayi
- Basamaklarina Ayirma (mod ve bolme)
- Algoritma Izleme (Trace)
- Diziler (Arrays) ve ortalama hesaplama
- Sartli Ifadeler (If-Else)
